Shared Group Infrastructure (ADR-001 — ADR-005)

🔐 Keycloak SSO — unified identity (ADR-002) 🔍 Meilisearch — federated search (ADR-005) 📨 RabbitMQ — transactional outbox (ADR-003) 👥 EspoCRM — shared customer data (ADR-003) ⚡ ERP BU1 — :9001 (local to HomeStyle) ⚡ ERP BU2 — :9002 (local to WorkSpace)
Scenario A — Federated Commerce After Acquisitions. Each BU runs an isolated nopCommerce instance with its own PostgreSQL database (ADR-001). SSO via Keycloak lets the same customer identity log in to either brand. Orders flow asynchronously to EspoCRM through per-BU transactional outboxes. The ERP circuit breaker (ADR-004) lets one BU degrade without collapsing the other.
